# 视频生成画布工作台

从 0 开始，一步一步开发。第 1 步：只有一个画布页面。

## 第 1 步（当前线上版）

- 黑底 + 粒子背景，粒子跟随鼠标波动（紫色 / 粉色 / 青色 / 白色碎片）
- 画布上有一张分镜卡片，可以拖动
- 左下角放大 / 缩小 / 回到 100%，右下角“+ 加一张卡片”
- 没有右边面板、没有功能、没有保存——第 2 步再加

线上地址：https://buyanwz.github.io/video-canvas-workbench/

## 开发方式

每一步只加一个功能，你看了满意再做下一步。旧的 React Flow 版和单文件版已从本仓库删除。
