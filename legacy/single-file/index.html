重要：视频原片不要上传到这个工作台。本工作台不上传、不保存任何视频文件——大文件（尤其超过 1G 的原片）请放在云盘 / 对象存储里，只把链接填进卡片的“素材链接”字段。GitHub 单个文件限 100MB、仓库约 1GB，也放不下大视频。画布里只存分镜、台词、提示词和链接。

项目

画布 — 点一张卡片，右边就能改它；拖卡片上下换顺序

已预装“面馆示例”6 条。改完自动保存在这台浏览器（IndexedDB，空间比 localStorage 大得多；不支持时自动用 localStorage）。换电脑 / 发给工作室同事时，用右边的“导出 / 导入 JSON”搬运项目。

转换结果预览

点一张卡片上的功能按钮，或点“复制全部转换提示词”后这里会显示。

右边 · 可视化编辑

不用写代码，点左边卡片，右边直接改；想加功能，在下面“添加功能”里填个名字和模板就行。

1. 选中卡片

先点左边任意一张卡片。

2. 添加自定义字段

比如给选中的卡片加“参考图：图1”“配音：儿童男声”等，字段会显示在卡片上，也会进导出结果。

3. 添加功能

功能 = 一个可重复用的转换模板。占位符：{scene} 画面，{line} 台词，{who} 人物，{dur} 时长，{camera} 运镜，{sound} 音效，{time} 时间，{title} 标题。填好后它会出现在每张卡片上，点一下就按这个模板生成；“复制全部”用第一个功能模板。

4. 外观

颜色只改选中卡片，方便在画布上区分 A / B / 动作镜头。

5. 数据与带走

这个工作台可以整个带走：代码在 GitHub 仓库里，项目数据用下面导出成 JSON。账号、浏览器、电脑换了都没关系，重新打开页面再导入 JSON 就行。视频原片不在 JSON 里，只存链接，记得另外备份原片。
